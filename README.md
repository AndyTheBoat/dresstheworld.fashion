# DressTheWorld fashion diary

Static local website. Open index.html for the opening collage and complete journal.

The source image library has sequential chapters 01–18, hierarchical numbered subfolders, and folder-prefixed image filenames. Folder 19. Shorts contains extracts whose filenames match their canonical source images. Root images use prefix 00. Unique Shorts versions are preserved as additional canonical source images.

image-manifest.json maps current source paths to the existing optimized website images. Website asset URLs and chapter anchors remain stable. Entries marked unavailable were already absent from the source library; their optimized website images remain available.

No deployment was performed. See the image-library-renumbering folder in the Project Runway workspace for the rename plan and operation record.
