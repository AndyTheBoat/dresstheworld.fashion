# DressTheWorld fashion diary

Static GitHub Pages site. Open index.html, journal.html, or about.html.

The diary includes all 106 supplied raster images, individually captioned after visual review. The current source contains 18 numbered chapter folders (6a and 6b separate; 13 absent), supporting mood-board, backup, and atelier archive directories, a master board, and the _Short edit. It does not contain 24 chapter folders. No missing chapters were invented. The MP4 end card is not a photograph and is not presented as a collection film.

image-manifest.json maps each source-relative filename and SHA-256 to its optimized full image, thumbnail, dimensions, and caption. Source originals were read only. AI-assisted project imagery is identified on the site; casting visuals are not identified as personal portraits.

Deployment: main branch, repository root. Only AndyTheBoat/dresstheworld.fashion is in scope.
